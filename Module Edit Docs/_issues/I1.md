NOTE: The claim that the three interface resistances sum to the total systemic resistance was corrected
    on 2026-08-16. It is true as algebra inside the model but misleading as physiology, because the
    Interface II gradient is a vascular waterfall and no resistance dissipates it. Maas 2012 measured the
    two real resistances summing to 11.0 against a conventionally calculated total SVR of 16.6. The page
    now keeps the algebra and adds the caveat, and the Maas reference was added.
