SOURCE: The v2022 deck teaches tamponade incorrectly in two places. Slide 308: "one can detect this by
    noting a loss of x and y descent." Slide 309: "Tamponade causes loss of x and y descents." The x
    descent is preserved and usually dominant, because ejection is the only moment total cardiac volume
    can fall. Only the y is lost. Confirmed against Zhang, Kerins and Byrd, Echocardiography 1994, PMID
    10150627. Slide 308 also contradicts itself, since its own question asks why tamponade lacks a
    prominent y descent and its annotated figure marks loss of the y alone. The correct version is
    already in the library at pac-modules-patrick-lindsay-v1 slide 121, so the fix is a copy. These
    slides feed the N7 topic 3 bank and the sim-day items, so the error propagates.
